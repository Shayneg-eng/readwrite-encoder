# M1-M3: Data, Distillation Training, Eval and Scaling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the full v1 experiment pipeline: prepare text, cache teacher vectors, distill the read-write encoder, evaluate on STS-B, and benchmark scaling, so the whole experiment runs from one PowerShell script.

**Architecture:** Small focused modules under `src/rwe/`. Everything that touches Hugging Face (datasets, teacher, tokenizer) is imported lazily so the CPU test suite runs offline. Training consumes a `TokenStore` (flat int32 array plus offsets) and a cached fp16 teacher matrix, with length-bucketed batches built in the main process (no DataLoader workers, so it is Windows-safe).

**Tech Stack:** Python 3.10+, PyTorch, numpy, PyYAML, transformers, datasets, sentence-transformers (last three only for real runs), pytest.

**Spec:** `docs/specs/2026-09-29-readwrite-encoder-design.md`

## Global Constraints

- Teacher `all-MiniLM-L6-v2` (384-d); texts capped at 256 tokens; student uses the teacher's WordPiece tokenizer.
- Loss weights cosine 1.0, similarity-matrix 1.0, intermediate 0.2; AdamW peak LR 5e-4, 1k warmup, cosine decay, grad clip 1.0, batch 128.
- Mixed precision auto: bf16 if supported else fp16 with loss scaling. Checkpoints resumable.
- STS-B dev and test splits are never used for training and their sentences are excluded from the training text.
- Tests run on CPU and offline; nothing in `tests/` may touch the network.
- Pure PyTorch, native Windows.

## Tasks

Each task: write the tests first, run them to see them fail, implement, run them to see them pass, commit.

### Task 1: Tokenization, data store and batching
Files: `tokenization.py`, `data.py`; tests `tests/test_data.py`.
Interfaces: `HashTokenizer(vocab_size)(texts, max_len) -> list[list[int]]` with `.pad_id`, `.vocab_size`; `HFTokenizer(name)` same interface; `TokenStore.from_seqs/save/load/concat`, `store[i]`, `store.lengths`; `collate(seqs, pad_id) -> (ids, mask)`; `LengthBucketSampler(lengths, batch_size, seed, bucket_mult).epoch(e) -> list[np.ndarray]`.
Tests: store round-trip; collate shapes and mask; sampler covers only valid indices, no repeats within an epoch, and batches are more length-homogeneous than random batches.

### Task 2: Checkpoint, training loop, holdout eval
Files: `checkpoint.py`, `train.py`; tests `tests/test_train.py`.
Interfaces: `train(model, store, teacher, tc, device, n_train=None, eval_fn=None)`; `holdout_cos(model, store, teacher, start, end, device)`.
Tests: LR schedule shape; a synthetic bag-of-words task where holdout cosine to the teacher must exceed a threshold; checkpoint resume continues from the saved step.

### Task 3: Encode and STS evaluation
Files: `encode.py`, `eval_sts.py`; tests `tests/test_eval_sts.py`.
Interfaces: `spearman(x, y)`; `eval_pairs(encode_fn, a, b, gold) -> float`; `load_stsb(split)`; CLI comparing student and teacher.
Tests: Spearman on known values including ties; `eval_pairs` with a fixed encoder.

### Task 4: Data preparation and teacher cache
Files: `prepare_data.py`, `teacher_cache.py`; tests `tests/test_prepare_data.py`.
Interfaces: `clean(text) -> str`; `build(sources, limits, exclude, seed) -> list[dict]`.
Tests: cleaning, dedupe, per-source caps, exclusion of eval sentences, deterministic shuffle. The download and teacher-encode paths are exercised only on a real machine.

### Task 5: Scaling benchmark and synthetic experiment
Files: `benchmark_scaling.py`, `synthetic.py`; tests `tests/test_benchmark.py`.
Interfaces: `time_model(fn, lengths, batch, device, repeats) -> list[dict]`; `loglog_slope(lengths, times) -> float`; `TransformerBaseline`; `make_synthetic(...)`; `SyntheticTokenizer`.
Tests: log-log slope of student latency is roughly 1 on CPU.

### Task 6: Config, run script, docs
Files: `configs/base.yaml`, `scripts/run_all.ps1`, `requirements.txt`, `README.md`, `ORGANIZATION.md`.
